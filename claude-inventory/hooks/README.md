# hooks.json 주석 — 파일 안에 두지 않는 이유

훅 설정 파일에는 **문서에 있는 키만** 둔다. `_comment` 같은 임의 키는 스키마 검사에서
어떻게 취급되는지 확인된 바 없고, PreToolUse 훅이 로드에 실패하면 그 옆에 선언된
권한 가드까지 통째로 적용되지 않는다. 설명은 여기에 적는다.

## 스키마

`command` 는 **필수**, `args` 는 선택이며 **함께** 쓴다.

- `args` 가 있으면 **exec form** — `command` 가 실행 파일, `args` 가 인자 벡터.
  셸을 거치지 않아 경로에 공백·한글이 있어도 따옴표가 필요 없다.
- `args` 를 빼면 **shell form** — `command` 문자열 전체가 셸로 넘어간다.

> 2026-09-19 기록: `args` 만 남기고 `command` 를 지웠다가 되돌렸다.
> 공식 스키마에서 `command` 는 필수다. 원인(플러그인 미설치)을 확인하기 전에
> 이 파일부터 의심해서 멀쩡한 설정을 깨뜨린 사고였다.

## 경로

경로는 반드시 `${CLAUDE_PLUGIN_ROOT}` 로 잡는다. 상대경로로 두면 하위 폴더에서
세션을 시작할 때 **조용히** 실패한다 — 이전 하네스가 그랬다.

## matcher

`.*[Ff]igma.*` 로 넓게 잡고 실제 판정은 `block-figma-write.mjs` 가 한다.
Figma MCP 서버 이름이 환경마다 다르기 때문이다
(`mcp__Figma__` · `mcp__figma__` · `mcp__plugin:figma:figma__`).
여기서 정확히 맞추려 하면 놓친다.

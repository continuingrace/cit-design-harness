# 화풍 라우터

**화풍 스킬은 이 플러그인이 갖고 있지 않다.** 계정 스킬로 이미 있고, 여기서는 **고르고 넘기기만** 한다.
복사해 오면 SSOT가 둘이 되고 갈라진다.

> **먼저 CLI 버전을 본다 — 여기서 갈린다**
>
> 아래 스킬들은 claude.ai 계정에 연결된 스킬이라 로컬 `.claude/skills/` 폴더에는 없다.
> 디스크에서 찾으면 "없다"고 나오지만 세션에는 있을 수 있다. 단, 버전이 받쳐줘야 한다.
>
> | Claude Code 버전 | 계정 스킬 상태 |
> |---|---|
> | v2.1.273 이상 | 터미널 세션에 **동기화된다** — 이름 공간 접두사도 쓸 수 있다 |
> | v2.1.269 ~ 2.1.272 | 동기화 **안 됨** |
> | v2.1.269 미만 | 동기화 **안 됨** · 설령 보이더라도 **짧은 이름만** |
>
> **호출은 짧은 이름으로 한다** (`cit-comm-webtoon`). 접두사는 v2.1.273 이상에서만 의미가 있다.
> 안 보이면 아래 "안 보이면" 으로 간다 — 임의로 만들어 쓰지 않는다.

입력: **$ARGUMENTS**

## 1. 세트 선언을 먼저 확인한다

배색이 아직 안 정해졌으면 `/cit-design-harness:palette` 를 먼저 돌린다.
이미 정해졌으면 그 배색을 아래 스킬에 **그대로 전달**한다.

## 2. 화풍을 하나 고른다

| 콘텐츠 성격 | 화풍 | 넘길 스킬 |
|---|---|---|
| HR·조직 커뮤니케이션 웹툰, 인스타툰 | 미니미/치비 라인 | `cit-comm-webtoon` |
| B2B 반복 카드뉴스 시리즈 (예: 계정용 반복 포스트) | 라인 일러스트 / 종이 콜라주 | `b2b-insta-storycontents` |
| 팀 C·팀 D (예시) 꾸밈 일러스트 | 에디토리얼 라인 (색 면 포함) | `editorial-line-illust` |
| B2C 후기·스토리 (예: 고객 후기 계정) | 차콜 선묘 + 하프톤 | `editorial-halftone` |
| 잡지풍 2~3색 미니멀 | 리소그래피 | `riso-illustration` |
| 큐트 미니 캐릭터 | 크레용·색연필 | `crayon-drawing` |
| 굵은 선 컷만화 | 두꺼운 라인 | `thickline-cutcomic` |
| 글·아티클 삽화, 워크플로우 다이어그램 | 연필 손그림 | `illustration-maker` |
| 일회성·비브랜드 카드뉴스 | 그때그때 | `cardnews-image-prompt` |
| 위에 안 맞음 | — | `design-playbook` 에 판단을 맡긴다 |

**화풍은 섞지 않는다.** 한 세트에는 한 화풍이다.

### 고른 스킬이 안 보이면

만들거나 흉내내지 말고 **사용자에게 알린다.** 임의로 대체하면 화풍이 갈라진다.

**가장 흔한 원인은 CLI 버전이다.** 계정 스킬의 터미널 동기화는 **v2.1.273 이상**에서만 된다.
`claude --version` 으로 먼저 확인한다.

> "{스킬명} 이 이 세션에 없습니다.
>  계정 스킬의 터미널 동기화는 Claude Code v2.1.273 이상이 필요합니다 — 버전을 확인해주세요.
>  이 화풍이 꼭 필요하면 업데이트 후 다시, 아니면 다른 화풍으로 갈지 정해주세요."

그리고 **누락된 채로 진행하지 않는다.** 다음 단계를 멈추고 사용자 판단을 받는다.

## 3. 넘길 때 함께 전달한다

고른 스킬을 호출하면서 세트 선언의 값을 같이 준다.

```
배색      {세트 선언의 주색 · 포인트}
규격      {1080×1350 / 1920×1080 / …}
장수      {N}
톤        {주제에서 읽은 정서}
```

## 4. 받은 뒤

프롬프트를 받아 이미지를 만들고 Figma에 배치한 다음,
반드시 `/cit-design-harness:preflight` 로 검수한다.

## 하지 않는 것

- 화풍 스킬의 내용을 여기로 복사하지 않는다
- 한 세트에 두 화풍을 섞지 않는다
- 배색을 여기서 새로 정하지 않는다 — 세트 선언을 따른다
- 없는 스킬을 비슷한 것으로 몰래 대체하지 않는다

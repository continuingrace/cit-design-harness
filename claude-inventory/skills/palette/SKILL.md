# 세트 선언 — 게이트 A

작업 단위는 낱장이 아니라 **캠페인 세트**다. 주제 하나에 채널별 산출물이 딸린다.
그러니 배색도 장마다 정하지 않고 **세트당 한 번** 정하고, 그 세트의 모든 채널이 상속받는다.

주제: **$ARGUMENTS**

## 1. 먼저 읽는다

- `${CLAUDE_PLUGIN_ROOT}/design-language.md` — 확정 규칙과 템플릿
- `${CLAUDE_PLUGIN_ROOT}/spec.json` — 기계 판정값

## 2. 채널 구성을 묻는다

기존 작업의 세트 구성은 대개 이렇다. 무엇이 필요한지 확인한다.

```
홈페이지·블로그 ▼    세로 상세 · 썸네일 1080×1350
PPT·줌배경 ▼        16:9 장표 1920×1080 · 줌 배경 1920×1080
인스타그램 ▼        4:5 카드뉴스 1080×1350 (표지 1 + 본문 N)
광고 ▼              메타 4:5 1080×1350
카카오 ▼            800×600
```

## 3. 배색을 정한다 — 세트당 한 번

**색은 고정하지 않는다.** 주제와 정서에 맞춰 매번 새로 고른다. 다만 구조 규칙은 지킨다.

| 규칙 | 내용 |
|---|---|
| 포인트 컬러 | 화면당 **1개**. 헤드라인 안에서는 **1개 구절에만** |
| 본문 색 | 무채색(검정/흰색). 컬러 본문 금지 |
| 대비 | 본문 4.5:1 이상, 큰 제목 3:1 이상 |
| 사진 위 텍스트 | 반드시 오버레이를 깔고 올린다 |

정한 배색은 **세트 전 채널에 동일 적용**한다. 인스타만 다른 색이면 세트가 아니다.

## 4. 선언문을 출력한다

아래 형식으로 짧게 낸다. 이후 모든 작업이 이 선언을 따른다.

```
■ 세트 선언 — {주제}

배색      주색 {hex} · 포인트 {hex} · 본문 {무채색}
근거      {왜 이 색인가 한 줄}

채널
  인스타 4:5   표지 1 + 본문 N   좌우 112px / 72px
  광고 4:5     N장               좌우 96px · 하단 240px 비움
  PPT 16:9     N장
  {…}

적용 규칙
  서체        ExampleSans
  자간        −1.5%
  파일명      {YYMMDD}_{종류}_{본부}_{번호}_{버전}
```

## 5. 넘긴다

- 이미지 소스가 필요하면 → `/cit-design-harness:route` 로 화풍을 고른다
- 다 만든 뒤에는 → `/cit-design-harness:preflight` 로 검수한다

## 하지 않는 것

- 색을 브랜드 고정색으로 박지 않는다 — 매번 정한다
- 세트 안에서 채널마다 다른 배색을 쓰지 않는다
- 확정 규칙(서체·자간·마진)을 임의로 바꾸지 않는다 — 바꿔야 하면 사람에게 먼저 말한다
